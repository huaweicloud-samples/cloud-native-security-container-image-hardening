# 架构说明

> 本文档为华为云实践架构说明，供部署与运维参考。

## 1. 概述

本实践构建一套**容器镜像加固流水线**：在私网构建环境中，基于加固 Dockerfile 将基础镜像更新至最新安全补丁并应用操作系统安全基线（内核参数、umask、文件权限、最小化运行时），产出满足安全加固要求的「黄金」容器镜像；流水线支持**定时重建**（默认每周五 06:00）与**漏洞联动重建**（扫描发现高危/严重漏洞后自动重建），并通过消息通知将构建与扫描结果推送给订阅者。

## 3. 组件说明

| 组件 | 华为云服务 | 职责 |
|-|-|-|
| 网络 | 复用已有 VPC + 公网 NAT | 构建子网建在已有 VPC（10.0.0.0/16）内，经已有 NAT 的 SNAT 自动出网，不新增网络资源 |
| 构建 | CodeArts Pipeline + Build | 执行加固 Dockerfile 构建容器镜像并推送 SWR；支持定时（每周五 06:00）与事件触发 |
| 镜像 | SWR（组织 + 仓库） | 存储加固镜像；KMS 加密 |
| 加固物料 | OBS（资源桶） | 托管加固组件 YAML 与加固 Dockerfile |
| 加密 | DEW KMS | 镜像与 OBS 桶加密 |
| 扫描 | HSS 镜像扫描 + FunctionGraph | 定时扫描最新镜像，高危/严重漏洞联动重建 |
| 通知 | SMN | 构建/扫描结果通知订阅者 |
| 可观测 | VPC 流日志 → LTS | VPC 流量审计 |
| 权限 | IAM 委托 | FunctionGraph 执行权限（SWR/HSS/Pipeline/SMN） |

## 4. 加固内容

加固逻辑由 `src/build/` 承载，构建流水线按序应用：

1. **系统安全更新**（`components/01-system-update.yml`）：`dnf update --security` 将基础镜像更新至最新安全补丁；
2. **操作系统安全基线**（`components/02-baseline-hardening.yml`）：内核参数（禁接受重定向、TCP syncookies、地址空间随机化）、umask 027、profile 权限收紧；
3. **最小化运行时**（`components/03-minimal-runtime.yml`）：清理包缓存，降低镜像体积与攻击面。

加固 Dockerfile（`Dockerfile.hardened`）将这些规则固化为可复现的构建步骤。

## 5. 事件链路

| 链路 | 触发 | 动作 |
|-|-|-|
| 定时重建 | 每周五 06:00（CodeArts Pipeline 调度） | 重新执行加固构建 → 推送 SWR 新标签 |
| 漏洞联动重建 | FunctionGraph 每 6 小时查询 HSS 扫描结果 | 高危/严重漏洞 → 触发流水线重建 + SMN 通知 |
| 结果通知 | 构建/扫描事件 | SMN 邮件通知订阅者 |
